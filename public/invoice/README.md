Optional invoice artwork. Every file here is optional — a missing one falls back
to type or a drawn shape, so the invoice always renders.

  mascot.png     standing mascot for "manage your subscription"
  badge.png      gold plan ribbon / crown
  signature.png  authorised-signature script
  footer.png     circular mascot for the footer band

PNG with transparency. Drop a file in and it appears on the next render — no
code change and no deploy of this directory's contents is special-cased.
