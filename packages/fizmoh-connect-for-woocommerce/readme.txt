Connect your WooCommerce store to Fizmoh Cloud for automated WhatsApp order updates, multi-stage abandoned cart recovery, and newsletter synchronization.

== Description ==

Fizmoh Connect is the official WooCommerce integration for the Fizmoh WhatsApp Marketing and Conversational Commerce platform.

= Key Features =
* **Instant WhatsApp Order Tracking**: Automatically notifies customers on WhatsApp when orders are created, processing, shipped (with live courier tracking link), or cancelled.
* **Shipment Tracking Integration**: Supports official WooCommerce Shipment Tracking, Advanced Shipment Tracking (AST), and ShipStation.
* **Real-Time Abandoned Cart Capture**: Captures customer contact information *as they type* on checkout and automatically triggers multi-stage recovery messages with 1-click cart restoration.
* **WhatsApp Newsletter & Checkout Opt-In**: Adds a customizable WhatsApp consent checkbox on checkout and provides the `[fizmoh_newsletter_box]` shortcode.
* **Storefront WhatsApp Widgets**: Floating WhatsApp chat button and 1-click "Order via WhatsApp" button on product pages.
* **HPOS Compatible**: High-Performance Order Storage (Custom Order Tables) fully supported.

== Installation ==

1. Upload the `fizmoh-connect-for-woocommerce` folder to `/wp-content/plugins/` directory, or upload the `.zip` file via WordPress Admin -> Plugins -> Add New -> Upload Plugin.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Go to WooCommerce -> Fizmoh Connect.
4. Enter your Fizmoh Workspace API Key and API Endpoint, then click 'Test Connection'.
5. Enable the notifications and features you wish to automate!
